# CV files

Drop both versions of your CV into this `public/` folder so visitors can pick:

- `Mazhar-Hayat-AI-Architect-CV.docx` (Word, editable)
- `Mazhar-Hayat-AI-Architect-CV.pdf`  (PDF, recruiter-friendly, ATS-safe)

To generate the PDF from Word: **File → Export → Create PDF/XPS**.

If the PDF is missing, the "PDF" option in the download dropdown will still
appear but the file download will 404. The DOCX option always works.
